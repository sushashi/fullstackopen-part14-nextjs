## Welcome to Blog App

This is a modern blogging platform built with Next.js that allows users to bookmark blog posts
from a diverse range of authors, create personalized reading lists, and track blogs as read or
unread through a clean, intuitive interface.

### Features

- **Create and Manage Blog Posts** - Submit and manage blog posts for others to discover and read
- **User Profiles** - Personalized user pages for managing activity and reading preferences
- **Authentication** - Secure login and registration
- **Read Tracking** - Mark posts as read or unread for better reading management
- **API Integration** - Retrieve and display blog data dynamically through APIs
- **Modern UI** - Clean, responsive, and intuitive interface built with Next.js

### Getting Started

To start exploring:

1. [Register](/register) for a new account
2. [Login](/login) to access your dashboard
3. [Create a new blog post](/blogs/new)
4. View [all blogs](/blogs) and [users](/users)
5. View your [personnal page](/me)
